# 第3作目：NEXUS FITNESS STORY LP

第2作目のNEXUS FITNESSを題材に、スクロール連動のストーリー表現を学ぶための発展版ランディングページです。

## コンセプト

**「スクロールするほど、理想の身体に近づいていく。」**

大きな写真と短いコピーを組み合わせ、設備、グループクラス、個別指導を順番に紹介します。

## 主な構成

1. スクロールズーム付きヒーロー
2. ブランドメッセージ
3. 固定式の設備ストーリー
4. 選ばれる3つの理由
5. 3つの料金プラン
6. 入会までの3ステップ
7. 無料施設見学へのCTA

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- IntersectionObserver
- requestAnimationFrame
- CSSカスタムプロパティ

外部アニメーションライブラリは使用していません。

## アクセシビリティ

- 本文へのスキップリンク
- キーボード操作時のフォーカス表示
- 画像の代替テキスト
- `prefers-reduced-motion` による動きの抑制
- JavaScriptが動かない場合の通常表示
- スマートフォンで固定スクロール演出を解除

## 確認方法

`index.html` をブラウザで開いて確認できます。ローカルサーバーを使用すると、より実際の公開環境に近い状態で確認できます。
