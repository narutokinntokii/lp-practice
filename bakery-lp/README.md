# 第1作目：ベーカリー こもれび LP

住宅街にある家族向けの架空のパン屋「Bakery こもれび（ベーカリー こもれび）」のランディングページ（LP）です。

## コンセプト
**「家族の毎日に寄り添う」**
近所の人たちが日常的に立ち寄りたくなる、温かみと安心感のあるお店。

## ターゲット
近隣の住宅街に住むファミリー層、地域の方々（スマートフォン閲覧を重視）

## 看板商品
- 発酵バターの贅沢クロワッサン

## 構成
1. ヘッダー（ロゴ・ナビゲーション）
2. ファーストビュー（メインビジュアル・キャッチコピー）
3. お店のこだわり（About / 3つの特徴）
4. 看板商品（クロワッサン紹介）
5. おすすめ商品（食パン・カレーパン・フルーツデニッシュ）
6. 店舗情報・アクセス（営業時間・架空の所在地・注記）
7. フッター（著作権表記）

## 使用技術
- HTML5（セマンティックマークアップ）
- CSS3（モバイルファースト・レスポンシブデザイン）
- Git / GitHub
