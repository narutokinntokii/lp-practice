# 第2作目：NEXUS FITNESS LP

最新鋭の設備を訴求する架空のフィットネスジム「NEXUS FITNESS」のランディングページです。

## コンセプト

**「最新鋭の設備で、理想の身体を最短で。」**

設備、グループクラス、個別指導という3段階の価値を分かりやすく伝え、無料の施設見学につなげます。

## 主な構成

1. ファーストビュー
2. 最新設備の紹介
3. 選ばれる3つの理由
4. グループクラス
5. 3つの料金プラン
6. パーソナルトレーニング
7. 入会までの流れ
8. 店舗情報・アクセス
9. 無料見学フォーム

## 料金プラン

- 基本プラン：月額2,000円（税込）
- プレミアム：月額4,000円（税込）
- パーソナル：月額15,000円（税込）
