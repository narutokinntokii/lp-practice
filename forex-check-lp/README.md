# 第4作目：為替日和

外部の実データを自動取得する、日本語の為替チェックLPです。HTML / CSS / Vanilla JavaScriptだけで動作し、ビルド・APIキー・追加ライブラリは不要です。

## 確認方法

このフォルダの `index.html` を現在のChrome / Edge等で開いてください。インターネット接続とJavaScriptが必要です。ローカルHTTPサーバーでも表示できます。公開ページは [GitHub Pages](https://narutokinntokii.github.io/lp-practice/forex-check-lp/) です。

## 機能

- USD / EUR / GBP / AUDの対円参考レート、各基準日
- タブで円→外貨 / 外貨→円を切替。円は1,000円刻み、外貨は1通貨単位で増減。各方向の入力金額を保持。
- 選択通貨の30 / 90 / 365日前からの推移、期間始点比、日別データ表
- 初回表示と再取得ボタンによる取得。通貨・期間変更でグラフを再取得
- 15秒タイムアウト、通信・HTTP・不正応答エラー、再試行、連続切替時の古いリクエスト中断
- レスポンシブ表示、キーボード操作、状態通知、グラフの代替説明・数値表

## API・出典と加工

2026-10-04に [Frankfurter公式仕様](https://frankfurter.dev/) と [ECB利用条件](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) を確認。

`https://api.frankfurter.dev/v2/providers/ecb/rates` のみを使用します。既定の複数提供元混合データは使いません。

- 最新：`?base=EUR&quotes=JPY,USD,GBP,AUD`。同一基準日の応答を確認し、JPY値 / 各通貨値でクロスレートを算出（EURの分母は1）。
- 推移：`?base=USD&quotes=JPY&from=YYYY-MM-DD&to=YYYY-MM-DD` 等。APIによるクロスレートを使用。
- 円→外貨＝入力した円の金額÷対円レート。外貨→円＝入力した外貨の金額×対円レート。変化率＝（期間末値 / 期間初値 − 1）×100。表示小数は丸め、内部計算は未丸め値を使用。
- 土日祝等、値が公表されない日は補間データを生成しません。グラフの線は実在する公表日の点を結びます。期間変化は最初と最後の取得値の比較です。

ECBの出典・無料入手先・加工内容・利用条件へのリンクを画面に表示しています。参考レートは日次であり、リアルタイム相場・決済額・投資判断用の価格ではありません。手数料は含みません。

## 制約

APIの稼働、通信環境、CORSに依存します。失敗時に架空の値や保存値へ置き換えません。ブラウザの日時が取得期間に使われます。バックグラウンド定期取得やキャッシュは初版では設けていません。API提供元の仕様・利用条件は公開前にも再確認してください。
